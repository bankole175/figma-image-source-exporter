Figma Image Source Exporter

Bulk-copy the original links of images that stock-photo plugins (Unsplash, Pexels and others) placed in your Figma file, instead of clicking "View image on …" one layer at a time.

How it works and privacy

Some stock-photo plugins save the photo's link on each layer they fill. You can tell because a button like "View image on Unsplash" appears under Tools in Figma's right sidebar. Figma's API lets anyone with access to the file read that saved data. This page asks Figma's API for it and lists every link it finds.

The page runs entirely in your browser. Your token is sent only to api.figma.com. It's never sent anywhere else, and it's kept only in this browser if you tick "Remember".

Images added by plugins that don't save their source (or pasted or dragged in by hand) have no link to recover.
